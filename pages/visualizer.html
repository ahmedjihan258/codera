How Bubble Sort Works

Bubble Sort repeatedly steps through the list, compares adjacent elements, and swaps them if they're in the wrong order. The largest element "bubbles" to the end after each pass.

for i from 0 to n-1:
  for j from 0 to n-i-2:
    if arr[j] > arr[j+1]:
      swap(arr[j], arr[j+1])

Time Complexity:  O(n²)
Space Complexity: O(1)

/* for loop */

  console.log("i =", i);

  console.log("i =", i);

}
